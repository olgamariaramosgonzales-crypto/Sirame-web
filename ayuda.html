Ayuda

Preguntas frecuentes

Respuestas rápidas sobre cómo funciona SIRAME, el acceso y los costos. Si no encontrás lo que buscás, escribinos desde Contacto.

¿Por qué elegir SIRAME en lugar de usar hojas de cálculo como Excel?
Excel no ofrece control de acceso estricto por roles, permite la modificación accidental o intencionada de datos sin dejar registro y no valida si un número de inventario se duplica. SIRAME garantiza la trazabilidad inalterable de quién realizó cada movimiento, aplica seguridad bancaria en claves (bcrypt) y actualiza los datos de forma atómica con transacciones MySQL (COMMIT / ROLLBACK).
¿El sistema funciona sin conexión a internet?
Sí. En su modalidad On-Premise (servidor local), SIRAME funciona al 100% dentro de la red local (LAN) de la institución sin necesidad de contar con acceso a internet.
¿Qué ocurre si un equipo registrado se cambia de aula u oficina?
El usuario con rol de Coordinador o Administración registra el movimiento en el módulo de Traslados. El sistema guarda la fecha, motivo, origen, destino y responsable, y actualiza de manera automática e instantánea la ubicación actual del equipo en la base de datos.
¿Cómo garantiza el sistema la seguridad de las contraseñas?
Las contraseñas no se almacenan como texto plano. SIRAME utiliza la librería bcrypt para aplicar un algoritmo de hash criptográfico con "sal" (salt), lo que impide que incluso los administradores del sistema puedan ver la clave real de los usuarios.
¿Un profesor puede dar de baja un equipo que se arruinó?
No. El profesor solo tiene permiso para cambiar el estado del equipo a "Dañado" o reportar la incidencia. La baja definitiva del inventario requiere de una verificación y procesamiento por parte del Coordinador o la Administración.
¿Se pueden recuperar datos si ocurre un fallo en el equipo donde se instaló el sistema?
Al estar basado en MySQL, el sistema permite programar respaldos (backups) automáticos periódicos de la base de datos. En caso de fallo del equipo cliente, solo se reinstala la aplicación ejecutable de Python sin perder la información almacenada en el servidor.
¿El sistema se puede personalizar con el logotipo e imagen de nuestra institución?
Sí. SIRAME cuenta con un panel visual configurable que permite adaptar la paleta de colores corporativos, la iconografía y el logotipo oficial en el encabezado y en el panel lateral de navegación.
¿Qué requisitos técnicos mínimos necesita una computadora para ejecutar SIRAME?
Para el cliente de escritorio se requiere cualquier computadora con sistema operativo Windows 10/11, Linux o macOS, con al menos 2 GB de RAM y 200 MB de espacio en disco. Para el servidor de base de datos se recomienda un procesador de 2 núcleos, 4 GB de RAM y MySQL Server 8.0 o superior instalado.
¿Cómo solicito acceso al sistema?
Completá el formulario en Solicitar acceso con tus datos institucionales y el rol que necesitás. Administración revisa cada solicitud y habilita tu usuario.
